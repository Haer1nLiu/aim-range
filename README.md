# 自瞄靶场

一个单机网页射击小游戏。你守在屏幕中间的炮台，无人机从四面八方冲过来。
可以随时在三种瞄准模式之间切换，直观感受「自瞄」到底有多夸张。

纯 HTML + CSS + JavaScript，没有任何依赖，也不需要安装。

## 怎么运行

- **在线玩**：<https://haer1nliu.github.io/aim-range/>
- **本地玩**：下载后直接双击 `index.html`，用浏览器打开

## 操作

| 按键 | 作用 |
|---|---|
| 鼠标 / 按住左键 | 瞄准 / 开火（手机上用手指） |
| `1` | 手动：自己瞄、自己开火 |
| `2` | 辅助瞄准：准星被圆圈里的敌人吸过去，开火还得自己按 |
| `3` | 暴力自瞄：全屏锁定、预判走位、自动开火 |
| `E` | 开关透视框（显示距离和血量） |
| 空格 | 暂停 / 继续 |

## 敌人

| 名字 | 特点 | 分数 |
|---|---|---|
| 无人机 | 普通速度，直线冲过来 | 10 |
| 疾风 | 速度快，左右大幅晃动，手动很难打中 | 25 |
| 重甲 | 慢，但要打 5 枪，撞到扣血最多 | 60 |

每 15 秒升一波，怪会越来越快、越来越多。

## 自瞄是怎么做到百发百中的

暴力自瞄并不是简单地「瞄准敌人现在的位置」。子弹飞过去需要时间，敌人在这段时间里会移动，
所以程序会按照敌人自己的移动规则，把它未来的路线往前推算，找到「子弹到达那一刻敌人正好在的位置」，
再朝那里开火（见 `src/game.js` 里的 `futurePos` 和 `leadPoint`）。
它还会记录每个敌人身上「已经在路上的子弹」，够打死它就换下一个目标，不浪费子弹。

> 这只是一个单机演示游戏，用来体验和理解瞄准算法。请不要在和别人对战的真实游戏里使用作弊程序。
